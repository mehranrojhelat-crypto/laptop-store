# 💻 Laptop Store – فروشگاه آنلاین لپ‌تاپ

فروشگاه مدرن و کاملاً فارسی لپ‌تاپ ساخته‌شده با **Next.js 16**، **React 19**، **Tailwind CSS 4** و **shadcn/ui**.

یک تجربه خرید سریع، زیبا و کاربرپسند با دسته‌بندی‌های مختلف، سبد خرید، پرداخت، احراز هویت و تم تاریک/روشن.

---

## ✨ ویژگی‌ها

- 🏠 صفحه اصلی جذاب با هیرو، دسته‌بندی‌ها، پرفروش‌ها و پیشنهادات ویژه
- 🛒 لیست محصولات با فیلتر بر اساس دسته‌بندی (گیمینگ، اولترابوک، اداری، مهندسی، دانشجویی)
- 🛍️ سبد خرید و صفحه پرداخت (Checkout)
- 👤 سیستم ورود، ثبت‌نام و پروفایل کاربر
- 🌙 پشتیبانی از تم تاریک و روشن
- 📱 طراحی کاملاً ریسپانسیو (موبایل، تبلت، دسکتاپ)
- ⚡ رابط کاربری مدرن با انیمیشن‌های نرم
- 🛡️ گارانتی، ارسال سریع و پرداخت امن (بخش‌های تبلیغاتی)

## 📦 نصب و راه‌اندازی

### پیش‌نیازها
- Node.js 18 یا بالاتر
- pnpm (پیشنهادی) یا npm / yarn

### مراحل نصب

```bash
# کلون کردن پروژه
git clone https://github.com/mehranrojhelat-crypto/laptop-store.git
cd laptop-store

# نصب وابستگی‌ها
pnpm install
# یا
npm install

# اجرای پروژه در حالت توسعه
pnpm dev
# یا
npm run dev
