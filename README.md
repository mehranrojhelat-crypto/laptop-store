# 💻 Laptop Store – فروشگاه آنلاین لپ‌تاپ

فروشگاه مدرن و کاملاً فارسی لپ‌تاپ ساخته‌شده با **Next.js 16**، **React 19**، **Tailwind CSS 4** و **shadcn/ui**.

یک تجربه خرید سریع، زیبا و کاربرپسند با دسته‌بندی‌های مختلف، سبد خرید، پرداخت، احراز هویت و تم تاریک/روشن.

---

## ✨ ویژگی‌ها

- 🏠 صفحه اصلی جذاب با هیرو، دسته‌بندی‌ها، پرفروش‌ها و پیشنهادات ویژه
- 🛒 لیست محصولات با فیلتر بر اساس دسته‌بندی (گیمینگ، اولترابوک، اداری، مهندسی، دانشجویی)
- 🛍️ سبد خرید و صفحه پرداخت (Checkout)
- 👤 سیستم ورود، ثبت‌نام و پروفایل کاربر
- 🌙 پشتیبانی از تم تاریک و روشن
- 📱 طراحی کاملاً ریسپانسیو (موبایل، تبلت، دسکتاپ)
- ⚡ رابط کاربری مدرن با انیمیشن‌های نرم
- 🛡️ گارانتی، ارسال سریع و پرداخت امن (بخش‌های تبلیغاتی)

## 📦 نصب و راه‌اندازی

### پیش‌نیازها
- Node.js 18 یا بالاتر
- pnpm (پیشنهادی) یا npm / yarn

### مراحل نصب

```bash
# کلون کردن پروژه
git clone https://github.com/mehranrojhelat-crypto/laptop-store.git
cd laptop-store

# نصب وابستگی‌ها
pnpm install
# یا
npm install

# اجرای پروژه در حالت توسعه
pnpm dev
# یا
npm run dev
سپس مرورگر را باز کنید و به آدرس زیر بروید:

http://localhost:3000
📁 ساختار پروژه
laptop-store/
├── app/                    # صفحات اصلی (App Router)
│   ├── about/              # درباره ما
│   ├── cart/               # سبد خرید
│   ├── checkout/           # پرداخت
│   ├── contact/            # تماس با ما
│   ├── login/              # ورود
│   ├── products/           # لیست محصولات
│   ├── profile/            # پروفایل کاربر
│   ├── register/           # ثبت‌نام
│   ├── globals.css
│   ├── layout.tsx
│   └── page.tsx            # صفحه اصلی
├── components/             # کامپوننت‌های قابل استفاده مجدد
│   ├── ui/                 # کامپوننت‌های shadcn
│   ├── product-card.tsx
│   ├── cart-provider.tsx
│   ├── auth-provider.tsx
│   ├── site-header.tsx
│   └── ...
├── lib/                    # توابع کمکی و داده‌ها
│   ├── products.ts         # لیست لپ‌تاپ‌ها و دسته‌بندی‌ها
│   ├── utils.ts
│   └── ...
├── public/                 # فایل‌های استاتیک (تصاویر لپ‌تاپ‌ها)
└── ...
📄 صفحات موجود
مسیر	توضیح
/	صفحه اصلی
/products	لیست تمام محصولات
/cart	سبد خرید
/checkout	صفحه پرداخت
/login	ورود کاربران
/register	ثبت‌نام
/profile	پروفایل کاربر
/about	درباره ما
/contact	تماس با ما
🚀 دستورات مفید
pnpm dev      # اجرای حالت توسعه
pnpm build    # ساخت نسخه پروداکشن
pnpm start    # اجرای نسخه پروداکشن
pnpm lint     # بررسی کد با ESLint
🎨 سفارشی‌سازی
لیست لپ‌تاپ‌ها و دسته‌بندی‌ها در فایل lib/products.ts قرار دارد.
استایل‌های سراسری در app/globals.css
کامپوننت‌های UI در components/ui
